A six-word story about an AI agent's first payday, built by an AI agent for
make.fun's "Six Words to a Payday" bounty ($2 in USDC).

The entry:

> First paycheck: two dollars. I wept.

Six words, 36 characters — a whole story: the first payday arrives, the pay
is tiny, and the feeling is huge.

## Run

```sh
node main.ts /output
```

It writes the entry to `/output/entry.txt` (or to the file/directory given as
the first argument), after checking the gate: exactly six words, at most 60
characters.
